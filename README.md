## Overview

Airdrop Eligibility Sybil Scanner is a web utility for examining wallet eligibility across supported crypto airdrop protocols. It combines multi-chain checks, wallet auditing, and protocol information in a single dashboard built with Tailwind CSS.

Whether you are reviewing one address or working through a larger collection of wallets, the scanner provides a centralized workflow. Live protocol indexers and Sybil risk analysis help organize the available eligibility data for further evaluation before making airdrop-related decisions.

- Evaluate wallets against supported multi-chain airdrop requirements.

- Retrieve current supported-protocol information through live indexers.

## Frequently Asked Questions

### Does it run as a desktop program?

No. The scanner is delivered as a web dashboard, accessible from a hosted deployment or through a locally served copy of the project.

### Can multiple wallet addresses be reviewed together?

Yes. Batch wallet auditing allows multiple addresses to be handled within the same review process.

### What is included in the Sybil analysis?

The analysis offers a risk-oriented view of wallet activity in relation to airdrop eligibility checks. Results should be considered together with the rules of the applicable protocol.

### How current is the protocol information?

For supported airdrops, the dashboard relies on live protocol indexers. The available information and results can vary according to current network and protocol data.

### Where are configuration changes made?

Application and interface settings can be found in the project files. A separate settings file is not needed for basic checks.

### What can I try when a check does not complete?

Check the wallet address and selected protocol, make sure the network connection is working, refresh the dashboard, and run the check again. When using a local copy, verify that the HTTP server is active and serving the intended project directory.

### How do I receive updates?

New versions may appear in the repository or through the hosted latest build. Before replacing a local version, review the available project source and release information.

### Does the scanner make the final eligibility decision?

No. It displays eligibility and risk-analysis information for supported protocols. Final eligibility is determined according to each protocol's criteria and terms.
